Modified 2026-11-03 for calvins-dad: 139-character supplement only; renamed;
native cubic curves translated +340 units vertically, with original advances
and horizontal geometry. Unrelated colour/layout tables and nonstandard tone
variation semantics excluded. Supplied as a separate AGPL font, with no
merging of its drawings into other fonts. Horizontal layout only is evaluated.

Complete corresponding source is downloadable alongside the webfont:
../sources/DadSealSans-source.zip
The app footer links directly to this package and the licence. The package
contains the complete pinned upstream repository (including UFO, FontCreator
project, data, licence and original font), the full modification source/recipe,
dependency versions and standalone build instructions. The final WOFF2 has a
byte-for-byte reproduction test using only that package.

Reference comparisons used Unicode chart images solely to check topology;
no chart artwork or embedded font program is a build input. All 139 forms
were inspected in actual strips; broader comic style and reader validation
are provisional. App export currently produces raster PNG pixels. Any future
font-program embedding/export needs its distribution terms considered again.
